# Alex Sekunau portfolio

The user supplied and selected the implementation brief and composition reference. This site implements that selected design as a static English portfolio in the current workspace.

Seven semantic sections form a continuous illustrated city journey. Original generated comic artwork supports readable HTML text. Cream informational sections contrast with sunset, cyan and magenta scenes. Anton display typography, DM Sans body copy and Caveat accents are locally hosted.

Vanilla ES modules handle navigation, motion preferences, environmental lifecycle, project panorama, project details, text and pointer interactions. Native dialogs provide focus containment and Escape handling. All substantive content is in HTML and remains available without JavaScript. A fine-pointer desktop panorama uses bounded sticky positioning and scroll progress; mobile and reduced motion retain a native carousel.

No invented contact email, availability, current location or historical dates. Project artwork is identified as original concept illustration, not a product screenshot. Only supplied professional contact destinations are used. The supplied CV now provides exact career dates, roles, email and Telegram. Eight project cards include the owner’s iOS applications AllergenChecker and Competition, AIBook and a corporate/marketing website with a blog on Nuxt and Directus. The counter and progress bar derive their totals from the actual cards.

Validation: production build, browser at multiple widths, no-JS fallback, keyboard dialogs, panorama boundaries, offscreen/visibility pausing and reduced motion. Document measured outcomes and remaining limitations in QA.md.
